# Internationalisation — v0.12.0-beta.1

The public application supports Spanish (`es`), English (`en`) and French (`fr`). Spanish is the default language. Every public route is prefixed with its locale; unprefixed requests are redirected to the saved `10tg-locale` preference or to `/es`.

Translations live in `lib/i18n.ts`. The Spanish dictionary defines the shared `Dictionary` type, so a new locale must implement the same structure. Football entities returned by Supabase (players, clubs, competitions and statistics) remain untouched and are never translated.

Each indexed localized page publishes a canonical URL and `hreflang` alternatives. `app/sitemap.ts` lists all three versions and `app/robots.ts` points crawlers to that sitemap. Placeholder games remain `noindex` until they are playable.

## Adding a language

1. Add its code and complete dictionary in `lib/i18n.ts`.
2. Add its Open Graph locale mapping in `app/[locale]/layout.tsx`.
3. Add its key to page alternates and the sitemap.
4. Add localized interactive copy to each client game.
