# 10 The GOAT

Plataforma de juegos de fútbol para 10thegoat.com.

## Stack
- Next.js 16
- React 19
- TypeScript
- Supabase
- Vercel

## Arranque
```bash
npm install
npm run dev
```

## Juegos iniciales
- Mayor o Menor
- Jugador Misterioso
- Football Grid
- Modo Carrera
- Mi XI
- Adivina el Escudo
